# Links and resources

A single place to find the external references used throughout these docs. All links point to official Stellar or project sources.

## Stellar developer docs

- [Stellar Developers](https://developers.stellar.org/) — the main entry point for Stellar documentation.
- [Stellar Docs: Introduction](https://developers.stellar.org/docs) — concepts, guides, and tutorials.
- [Stellar Docs: Build](https://developers.stellar.org/docs/build) — building on Stellar, including smart contracts.

## Soroban

- [Soroban documentation](https://developers.stellar.org/docs/build/smart-contracts/overview) — overview of Soroban smart contracts.
- [Soroban examples](https://github.com/stellar/soroban-examples) — sample contracts maintained by the Stellar team.

## SEP-41 (token interface)

- [SEP-41: Token Interface](https://github.com/stellar/stellar-protocol/blob/master/ecosystem/sep-0041.md) — the standard token interface used by Soroban tokens.

## Freighter wallet

- [Freighter website](https://www.freighter.app/) — the browser wallet for Stellar.
- [Freighter documentation](https://docs.freighter.app/) — setup and usage guides.

## Explorers and network tools

- [Stellar Expert](https://stellar.expert/) — block explorer and network analytics for Stellar.
- [Stellar Laboratory](https://lab.stellar.org/) — build and inspect transactions and contracts.
- [Horizon API reference](https://developers.stellar.org/docs/data/apis/horizon) — documentation for the Horizon REST API.

## Testnet

- [Stellar Testnet Friendbot](https://developers.stellar.org/docs/data/apis/horizon/api-reference/friendbot) — documentation for funding testnet accounts.
- [Friendbot (testnet)](https://friendbot.stellar.org/) — fund a testnet account by passing its public key as the `addr` query parameter.
- [Stellar Testnet](https://developers.stellar.org/docs/networks) — information about the Stellar networks, including testnet.
