last update to this page. It is sourced from the status sections of each
repository, so check those for the latest state.

## Contracts

The contracts live in
[`stellar-stream-hive-contract`](https://github.com/Stellar-Hive/stellar-stream-hive-contract).

- **Testnet:** deployed. The contract repository records the deployment date,
  contract IDs and WASM hashes in its
  [`DEPLOYMENTS.md`](https://github.com/Stellar-Hive/stellar-stream-hive-contract/blob/main/DEPLOYMENTS.md).
  Look the IDs up there rather than copying them from this page, because a
  redeploy creates new IDs.
- **Mainnet:** not deployed. The contract repository's `DEPLOYMENTS.md` says
  mainnet will only follow a successful testnet deployment, a completed audit,
  and explicit sign-off.
- **Audit:** not audited.

## Indexer API

The indexer lives in [`api/`](https://github.com/Stellar-Hive/stellar-stream-hive-api/tree/main/api)
and serves a read-only REST API.

- **Read-only.** The API exposes `GET` endpoints only and does not submit
  transactions.
- **In-memory state.** The index is kept in process memory with no database.
  A restart clears it, and the indexer then backfills from chain events again.
  See [API Overview](/docs/api/overview) for the backfill window.
- **Network.** The default endpoint is public testnet.

## Frontend

The web app lives in
[`stellar-stream-hive-frontend`](https://github.com/Stellar-Hive/stellar-stream-hive-frontend).

- **Testnet:** the default configuration targets testnet, using the testnet
  contract IDs published in the contract repository.
- **Mainnet:** the network setting accepts `mainnet`, but there is no mainnet
  deployment for it to talk to.

See the [Web App guide](/docs/web-app) for setup steps.

## What this page does not claim

- It does not claim an audit.
- It does not guarantee uptime or data retention for the testnet API.

If anything here disagrees with a repository's own status section or with the
